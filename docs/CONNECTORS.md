# Herramientas y contexto

El auditor funciona con el prompt y los datos del encargo. Un conector es opcional: usa únicamente fuentes pertinentes y autorizadas. No instales conectores, solicites claves API ni configures servicios externos por defecto.

Si falta acceso para comprobar una afirmación, identifica qué queda pendiente sin inventar búsquedas, capacidades, fuentes ni resultados. Disponibilidad técnica no equivale a autorización.

Los scripts de esta entrega no hacen llamadas a modelos. Las consultas reales que el usuario decida realizar pertenecen a su entorno autenticado; esta entrega no incluye credenciales ni integra una suscripción como credencial de un SDK.

Los archivos de instrucciones son contexto, no un mecanismo de aislamiento técnico. Comprueba las instrucciones globales, memoria, extensiones y permisos efectivos del entorno que utilices. No se promete aislamiento completo entre sesiones.
